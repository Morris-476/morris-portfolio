=============================================
  Morris 個人履歷網站｜開啟專案方式
=============================================

【第一步：開啟網頁預覽】

1. 開啟終端機（搜尋 cmd 或 PowerShell）
2. 輸入以下指令（按 Enter）：

   cd "C:\Users\user\OneDrive\Desktop\個人履歷"
   npm run dev

3. 看到 http://localhost:5173 後，開啟瀏覽器前往該網址

   ※ 若 5173 被佔用，看終端機顯示的實際網址（5174、5175...）


----------------------------------------------

【第二步：回到 Claude Code 對話】

1. 開啟終端機
2. 輸入以下指令（按 Enter）：

   claude -c

3. 即可繼續上次的對話

   ※ 若是第一次開啟，先輸入 claude 登入後再輸入 claude -c
